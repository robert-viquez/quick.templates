## Basic Workflow

1. Create a reusable template.
2. Save it in the root library or a folder.
3. Find it through search or Favorites.
4. Select it and press Enter to copy its content.

Use `Ctrl+Alt+V` to show Quick Templates and `Esc` to hide it.

## Storage and Backup

Templates are stored locally as UTF-8 Markdown files. The filename is the template name, its directory determines its folder, and the file body contains the copied text.

The library location can be changed from the Folders page. It can point to a locally synchronized cloud folder, such as OneDrive, to provide automatic backup through that provider. Quick Templates does not connect directly to a cloud service.

Application settings are stored in `%APPDATA%\Case Templates\settings.json`.

## Use Cases

- Customer support responses
- Repeated email follow-ups
- Project and operational status updates
- Development or operations runbook snippets
- Meeting-note templates
- Administrative and other repetitive text
