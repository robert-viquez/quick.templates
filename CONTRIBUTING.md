# Contributing

Issues, feature requests, documentation improvements, and pull requests are welcome.

## Development

Requires Windows 10 or 11 and Python 3.11 or later.

```powershell
git clone https://github.com/robert-viquez/quick.templates.git
cd quick.templates
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Keep pull requests focused and describe how the change was verified.
